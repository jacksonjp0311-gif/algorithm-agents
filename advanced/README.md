# Advanced

You are inside the part of the repository that is meant to be read slowly.

The root README gets a person running. This directory is the **shared inner room**: human conscience and AI hands looking at the same circuit. If Algorithm Agents is given to someone as a serious tool, this is the text that makes the gift hold.

Read in this order.

| File | Who it binds | What it is |
| --- | --- | --- |
| [COVENANT.md](COVENANT.md) | Human and AI | What must never be broken |
| [CIRCUIT.md](CIRCUIT.md) | Both | How intent moves through the living repo |
| [ROSTER.md](ROSTER.md) | Both | The twenty-six, by name and duty |
| [CMDS.md](CMDS.md) | Especially the AI | Commands as the only hands |
| [EXTEND.md](EXTEND.md) | Whoever adds a mind | How to grow the crew without becoming the archive |

Then return to work. The room is not a shrine you sit in. It is a standard you carry back to the terminal.

```text
HUMAN  —  names what should be sought
AI     —  runs the commands, reports what returned
AGENTS —  touch sources, write candidates
ARCHIVE — moves only on accept
```

If those four stay distinct, the tool stays clean. If any two collapse, stop.
